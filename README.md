# 🧠 EEG-Based Stress Detection System

An intelligent EEG-based stress detection application that analyzes EEG recordings and automatically classifies the user's stress level using Deep Learning (EEGNet).

---

## 🎯 Project Overview

This system processes EEG signals from EDF files and predicts stress levels through a trained EEGNet model.

* 19-Channel EEG Recordings
* 64-Channel EEG Recordings
